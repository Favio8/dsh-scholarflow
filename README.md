# ScholarFlow

当前实现基线为 **PRD / SPEC v1.21**（2026-10-15），沿用 v1.0–v1.20；包版本为 **1.21.0**。

v1.21 接通课程完整交付与已有研究结果成稿。创建时可明确选择目标，旧任务和快速首稿保持原行为；连续任务在后台准备、检查并多轮修订不可变候选，最后集中预览、一次采用，再检查实际保存稿并准备同快照文件。资料页支持作者结果的原值/定位/条件登记、CSV/JSON/制表文本映射预览、贡献/图表关联和版本更新；结果更新可连同关联论点形成新候选，保留人工稿与历史。任务根据实际检查和文件事实显示待检查、待采用、缺材料、待核对或就绪。

验证记录分开报告代码、自动化、真实宿主和任务内容质量。真实样例使用公开原论文及自编小基准的实际执行记录，科研结果保留原值、定位、条件和版本；由独立 Codex 审查原材料，不以生成模型自评替代核对。受控 TEST_ONLY 验证单独证明流程。Word 页数需要实际查看记录，tex 源文件不代表已编译 PDF。设计及逐项验收证据保存在工作区父目录 docs/task-delivery-v1.21/。安装宿主流程入口为 tests/e2e/v21-host.mjs --lifecycle 和 --research；真实任务入口为 tests/e2e/v21-real-task.mjs。
