## 开发与验证

`.github/workflows/ci.yml` 在每次推送到 `main` 与每个 PR 上跑 `pnpm install --frozen-lockfile`、
`pnpm build`、`pnpm typecheck`、`pnpm test`（windows-latest，固定 pnpm 11.5.2 与 Node 24）。
`pnpm typecheck` 现在同时检查 `src/**` 与 `tests/**/*.ts`；6 个 `.js` 测试仍在检查范围外，
原因写在 `tsconfig.json` 的 `include` 旁。
**CI 不含** `tests/e2e/**`（需要装好的 DSH Desktop、私有 `DSH_HOME` 与操作者凭据，部分会产生
真实费用）、`pnpm audit:appearance`（需要真实客户端与主题）与 `pnpm render:surfaces`（产物是
给人看的截图，不是门禁）——这些仍需按下面的命令手动执行。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm test
# 可选：真实安装环境，独立 DSH_HOME，不改 desktop profile
node tests/e2e/installed-host-smoke.mjs
# G0 与验收项的宿主层检查：隔离 profile、不调用模型、不产生费用
node tests/e2e/g0-probe.mjs
# 可选：使用现有 Host 凭据服务发起有限真实模型测试（会产生提供方费用）
node tests/e2e/installed-host-smoke.mjs --live-model
# 可选：三类 TEST_ONLY 教学论文，真实模型、每目标最多8次调用、模型会话重启恢复
node tests/e2e/installed-paper-types.mjs --live-model
```

## 正文工作区（2026-10-05）

正文默认显示 Markdown 源码与纸张预览，可切换编辑、预览或分屏；行号、字数和当前章节随编辑更新。
顶部显示项目标题、论文类型与排版／导出格式，原生 DSH 文件夹、应用下拉和更多操作继续复用。
项目设置、概览、资料与研究、大纲、审查、修改建议和运行历史收进“论文工具”，返回正文保持未提交缓冲。
Ctrl/Cmd+S 明确保存主稿；未提交编辑仍沿用浏览器与宿主暂存。已保存预览选区可附加到同一右侧会话。

Markdown 保持唯一正文事实源，格式切换不改写主稿。KaTeX 公式与字体本地打包，纸张预览不等同于编译 PDF。
导出支持真实 Word (.docx)、LaTeX (.tex) 和 Markdown (.md)，附 references.bib、质量报告和快照 manifest。
Word 公式保留 TeX 表达式；中文 LaTeX 使用 ctex，含引用时通过 BibTeX 处理 references.bib。
独立交付目录保存实际字节与哈希，支持完整 ZIP 下载或单文件下载；旧 Markdown 交付仍可读取。
导出含未保存编辑时，可选择“保存并导出”或“导出已保存版本”。

此轮按用户要求仅完成实现与构建，不新增或执行测试、界面自动验收；早期验证结果不代表此轮改动已验证。

2026-10-06 更新：原生新会话选择 ScholarFlow 即进入三页向导；确认后自动读取所选资料、组织证据与结构、连续生成首稿，并在中栏回答必要问题。支持暂停、继续、取消及重启检查点恢复。中栏保留 Markdown 人工编辑与预览，AI chat 和编辑器可按当前缓冲提出差异，用户接受后再保存。导出按钮直接下载所选 Word / LaTeX / Markdown；资料、引用、版本和问题按需查看。联网默认关闭，开启后使用 OpenAlex、Crossref 和实际获取的公开 PDF / HTML 文字；原始资料只读。

**本次更新未经测试**：按用户要求未新增或运行测试、类型检查、真实模型验证或界面自动验收。历史验证记录仅适用于各自记载的旧版本。实现边界见 [连续写作与双写决定](docs/decisions/continuous-writing-and-cowrite.md)。

## 入口、三步引导与结构预设（2026-10-06）

顶部 ScholarFlow 入口现在只打开插件设置：它渲染与全局设置页**同一个组件**，走同一命名空间与同一带版本校验的写入路径，两处不会出现两份配置。进入模式的唯一路径是「新建对话 → 模式选择」，打开已有的 ScholarFlow 会话仍会自动恢复工作台。

三步创建引导重做：**写作要求来源与参考材料独立选择**（文件或文件夹，文件夹按选择那一刻的成员展开、可逐个移除），每行标明可读取／图片／不可读取；提交格式与引用样式分列，作者—年份明确标为未实现；第二步合并为单一材料清单，不可读取的行禁用并写明原因，不再有独立分区。第三步由预设驱动：浏览、预览、跨类型**一次确认后原子应用**，章节可自由修改，篇幅接确定性分配（手工值保留、按权重分配、预算不足时一个数值都不改写），可保存为我的预设或更新已有用户预设。创建前确认区并入第三步，逐项交代写入目录、授权集合、外部处理、预算与能力缺口。

结构预设是插件级资源：`presets/structures/<paperType>/` 随包发布 12 个内置预设（每类 4 个，中英双语章节名与逐章写作重点），用户预设写 `<DSH_HOME>/scholarflow/presets/user/`，内置只读、可复制不可改删。改论文结构不会写回全局库。

门禁：`pnpm typecheck`、构建与 **392 项测试**全部通过。G0 验证结论见 [G0 记录](docs/decisions/g0-entry-presets-verification.md)：预设目录读写、目录选择器后端、三种导出编号一致（含 Word 编号表）、选模式不建目录、打开不重新初始化均已实测；外部来源经查证**无可用通道**，因此仍不可选且界面如实说明。过程中修复了 BibTeX 中文来源标题被丢弃的缺陷。

**尚未真机验收的部分**：八项交付验收中第 7、8 项（用户预设跨项目复用、改结构不覆盖全局库）已在隔离宿主验证；其余六项、图片识别（V4）与工作区外来源需要用户在场或授权后才能确认。


收尾验证（2026-10-07，PRD v1.2）：475 项自动化测试、54 项实际桌面 UI 和滚动／原生导航／三类任务／局部修改专项通过；窗口隐藏、减少动态效果、深浅主题和真实请求停止另有 7 项桌面检查。真实指定作业从空项目读取三张要求图片与完整 PDF，经真实修复与恢复生成 1574 汉字、九项分析；Word 16.0 和 LibreOffice 都为四页。质量报告保留 unknown，导出为工作稿，不声明教师评分或正式发布。实现、环境和逐项证据见 [收尾 ADR](docs/decisions/writing-experience-closeout.md) 和[产品工作区验收记录](../docs/writing-experience-quality/07-closeout-2026-10-07.md)。
