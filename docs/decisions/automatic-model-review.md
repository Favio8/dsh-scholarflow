# A fixed model review inside automatic progression

Date: 2026-10-05. PRD §7 and SPEC §10 authorize finite stages while retaining
operator control of manuscript changes. This extends local saved-fact
progression with an optional, separately previewed model review. Chapter
generation, research and revision dispatch are still separate stage plans.

The preview freezes the actual current manuscript, five semantic checks,
relevant selected evidence, confirmed memory, profiles, Skill versions and Host
model descriptor. Confirmation stores the exact review plan beside immutable
automatic input. Changing the selected model or scope stops the original
authorization. No model credentials enter project files or plugin settings.

Before execution, the parent atomically records one pending step with the
child's exact run ID and plan hash. The existing review executor may enter the
project only with a grant matching that current pending step and immutable
input. Each paid request revalidates the grant and uses the existing cumulative
workflow budget, including format repair and bounded transient retries. The
grant is an internal Core execution parameter, absent from public writing and
review request schemas. Ordinary independent paid stages remain excluded.

Completion requires the actual same-version report from that exact frozen
review, rather than a worker's success response. Original B0 findings and
unknown checks remain visible. The existing proposal acceptance and semantic
recheck rules continue to govern manuscript changes and issue closure.

Pause stops scheduling after the current finite model result is saved. Cancel
propagates immediately. A charged child with unknown outcome remains pending
and is never replayed by parent resume. A safely paused parent with a settled
report can explicitly resume in another Session and reuse the saved result.
The parent excludes only time actually recorded for the child; Host model
selection and validation still consume parent time. A deadline based on the
original remaining total budget also aborts slow preparation and model IO.

Private Skill reference scans include all automatic attempts and their fixed
review plans, before a child run exists and through verified project-copy
ancestry. Missing, changed or unknown records prevent treating a version as
unreferenced. Retirement continues to preserve original bytes.
