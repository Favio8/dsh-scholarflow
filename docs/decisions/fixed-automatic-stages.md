# Fixed automatic stages and review boundaries

Date: 2026-10-05. Sources: PRD §7.1, SF-024/027/033/034 and SPEC §10.

The existing seven-stage coordinator can dispatch one frozen research batch,
section/sequence candidate, or positioned issue revision per operator preview.
The preview records the actual provider/model, inputs, evidence, selection,
resources and original goal. The child inherits the original aggregate budget;
an exact persisted pending step grants only that run and plan admission.

Generation stops with a saved Proposal, leaving the manuscript unchanged.
Acceptance remains a separate guarded operator action. A subsequent preview
uses the actual accepted manuscript, including for deferred summary/conclusion.
Research preserves partial failures and stops for candidate/evidence selection.
Neither operation finishes the original goal or promotes metadata to evidence.
An unknown pending call is preserved rather than automatically replayed.

Stage success requires the real run, checkpoint and Proposal/search artifacts;
the worker's return value cannot establish completion. Private Skill references
include frozen automatic plans before children have been dispatched.

Reference filters count unique actually cited Source kinds, optionally intersected
with an explicit year window. The denominator is all actually cited sources.
Missing selected metadata remains unknown; Source kinds do not assert language
or peer-review status. Memory/Profile changes show positioned literal chapter
matches and affected checks while recording the limits of literal matching.

Keyboard previews are nonmodal and preserve access to the Host conversation.
They receive focus, Escape invokes the existing cancellation control, and closing
returns focus to the initiating control.

Consolidated typecheck/build and all 343 layered tests pass. Actual installed
Host verifies the finite section scheduler, operator acceptance, cold recovery,
original allowance, local correction and explicit provider reassessment.
See [final runtime validation](../final-runtime-validation.md) for native evidence.
