# 高版本项目只读查看

日期：2026-10-05。依据 PRD SF-030、SPEC 9.4 与文件保护边界。

配置、ledger 或资源锁任一 schemaVersion 高于当前支持版本时，项目进入专用只读页面。只读检查保存并返回原始文本与摘要；不将未来 ledger 转成当前类型，不忽略未来字段后继续写作，不降版本号，不执行事务恢复。正常操作入口和每次 Host 文件写入前重新检查版本，Core 主稿与 ledger 操作也拒绝高版本资源锁。

定位原稿仅使用配置中的项目身份及输出路径信封，不解释未来产品设置和记录。未知路径形状不猜测；相对路径、输出子树、敏感排除及 Markdown/BibTeX 扩展名必须通过。非法路径不读取目标，但保留元数据原文件供查看下载。原稿缺失、非普通文件或超过 2 MiB 只读预览能力时显示限制，不重建。元数据读取沿用已验证的 Host 文件通道和限额。

只读页面不显示正常六页写作控件，展示实际版本与诊断，原文件可展开查看并下载同一文本快照。预览显示最多 64000 字符；下载保留读取的原始 UTF-8 字节对应文本，包括 BOM 和换行。下载不是已审查交付，不产生质量标签，不修改主稿或配置。

领域测试覆盖三类独立版本升级、未知字段原文保留、无写入、原稿读取、主稿变更拒绝、敏感/越界/未知路径不读取、缺失与超限文件不重建。分层测试 205/205、类型检查通过。

真实 DSH 0.2.0-rc.2 原生 `g0` 测试通过：独立恢复后的 TEST_ONLY 项目逐项升级 ledger、资源锁和配置；页面显示只读入口且隐藏正常工作区页，原元数据和主稿下载摘要匹配磁盘原字节，每次主稿保存请求返回 PROJECT_SCHEMA_TOO_NEW，项目与原资料保留。每轮 smoke 使用新的独立 DSH_HOME，冷启动复用同轮目录，防止历史不支持项目影响其他轮的私有库引用审计。证据 `.dsh-tmp/g0-smoke.json` 忽略；完整 V1 验收仍在继续。
