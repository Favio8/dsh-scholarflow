# 引导目标的累计预算与未知调用

日期：2026-10-05。依据 PRD 7.2、SF-027、SF-028；SPEC 10 的累计预算、有限修复／重试与中断恢复约束。此落地包含阶段关联及统一计数，完整阶段自动调度仍待完成。

创建引导目标时冻结预算与模型审查轮次上限，原完整配置摘要用于追溯。另存权限政策摘要，包含项目身份／类型、输出范围、执行／预算配置、提供方选择、隐私、材料排除和格式。明确选择材料、配置阶段 Skill 或变更文风属于目标内的正常工作，使相关事实过期，不能由此重置总预算。权限政策改变阻止后续调用；同一阶段自己的全配置与资料摘要仍按原计划严格校验，需重新预览新发送范围。

写作／修订、模型审查和多查询检索的 input.json 保存 workflowId；单次查询与 DOI 计划也冻结此关联。任何在引导目标建立前预览的无关联计划，或已结束目标的旧执行计划，不能绕过当前累计计数。目标暂停时阻止新的阶段预览／请求，读取已有产物保持只读。

每次请求在网络调用前，通过项目写锁与事务更新 root checkpoint/run：保存唯一 callId、所属子运行、阶段、类型、实际执行进程、时间、候选上限预留和 pending 状态。不在写锁内调用提供方。模型格式修复和临时重试每次都占原额度；同一个审查运行的修复／恢复不增加审查轮次，新模型审查运行计入新轮。元数据查询和 DOI 核验共同计入查询预算；DOI 身份核验不增加文献候选计数。计数先保存再调用；发布中断可能保守记录未实际发出的请求，不能推断未计费并自动重放。

当前默认最大模型调用 40、查询 12、候选 80、模型审查 2 轮、执行 30 分钟，服从冻结的更低项目限额。候选预算在请求前预留上限，完整响应结算实际数量；失败没有完整结果时不纳入来源。进程损失的未知响应保留预留量。各子运行累计 activeDurationMs 与实际请求时长取增量最大值，不重复计入同一段执行时间；暂停后的用户等待不计入已经结算的执行时间，无应答的离线时间保守计入并封顶。后续请求使用整份目标的剩余时间信号；提供方等待与阶段结束时同步子运行时间。

根预算只允许一个 pending 请求，未结算或中断未知时阻止新调度。结束无应答必须经操作者预览／理由，实际进程存活时拒绝；进程已退出时可与对应旧子运行的非终态检查点并存处理，不接管其他运行。结束将调用记为 interrupted，保留费用、未知候选上限和原决定档案；恢复子阶段仍需原执行器的独立明确审批，不重放已保存结果。目标取消或交付必须先处理活动阶段／未知请求，不冒称已经停止网络请求。

真实模型验证中，短段落修复曾在默认 4096 输出 token 下耗尽推理输出而未完成 JSON；该调用和失败保留，原稿未改变。新写作计划与审查一致，明确冻结默认 16384 输出 token，在操作者预览显示，并按实际冻结值检查宿主上下文和发送请求。既有未声明输出额度的旧计划保持原 4096，不在恢复时静默增额；max-tokens 失败不自动重试或接受截断候选。

旧引导输入未冻结累计预算时保持可读，但禁止模型或查询派发，不用默认值重建其已用额度。预算阻止的 DOI 请求只保存失败尝试，原来源身份和 provenance 保持不变。根检查点与运行摘要原子提交；使用同一规范化序列化计算写入字节及摘要，避免新增可选字段导致恢复后摘要不一致。

实现入口：`src/core/pipeline/workflow-budget.ts`（累计预留、结算与时间同步）；`src/core/pipeline/workflow.ts`（输入／计划／检查点与未知调用确认）；各阶段执行器按该入口调用。根记录只保存 ID、摘要、计数、时间和进程信息，不保存模型密钥、响应错误正文或绝对项目路径。现已验证的 DeepSeek 文本 SDK 隐藏重试审计仍适用；其他模型路由审计尚未完成。

验证：`pnpm typecheck`、`pnpm test` 239/239 通过。八项新增集成检查覆盖真实领域执行器共享计数、格式修复、单次／批量／DOI 总额与身份保留、审查轮次、已结算时间去重、暂停／旧无关联计划拒绝、未知响应冷恢复与存活进程拒绝、事务故障先于 paid IO、明确选择资料后保持总额度和预算政策变化拒绝。模拟模型／提供方均为 TEST_ONLY。真实 DSH／Crossref 验证已通过，单次查询、DOI 与批次共计四次查询、七条元数据记录，未调用模型。真实 DSH／DeepSeek 模型验证已通过：章节、选区改写、取消、模型审查与问题修复共计五次调用、一个模型审查轮次；暂停恢复与后续材料／绑定变更保持原额度，预览／取消／读取不增加次数。失败的 4096 token 修复请求记录保留，后续新目标以明确冻结的 16384 token 完成验证；没有自动重试旧截断结果。本文的计数是已验证宿主路由的逻辑请求，不将未审计其他提供方的内部重试推定为已计入。
