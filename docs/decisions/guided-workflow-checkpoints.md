# 七阶段事实门禁与引导检查点

日期：2026-10-05。依据 PRD 7.1–7.2、SF-013、SF-027、SF-028 和 SPEC 10。此记录描述事实门禁及可恢复引导控制，不代表跨阶段自动调度和累计预算已完成。

用户明确本次研究问题与最低当前文本来源／定位证据数量，整体预览后保存目标。无正式要求时需说明理由；已登记要求仍必须明确确认，材料来源要求核对实际选择文件的当前摘要。元数据候选不算定位证据。大纲需用户确认完整结构且研究问题与本次目标一致；各章节通过 Markdown 源位置 AST 检查保存的正文，模型自报完成或仅有候选不算初稿。

同版审查依据已保存原稿、实际选择资料、配置、Profile、确认记忆、Skill 锁和论点等依赖。未知检查与全部旧未关闭问题保留。修订门禁检查当前选区候选版本、实际定位证据和可执行源码差异；仅在当前审查无未关闭问题时可说明理由跳过。用户也可说明理由保留问题结束修订，进入工作草稿交付；不关闭问题或提升证据支持。交付门禁核对当前正文与数据版本以及实际导出文件，保留工作草稿／已审查草稿质量标识。

每次确认冻结阶段输入摘要、产物 ID、实际 outcome、理由、时间和操作者会话，并保留不可变决定档案。相关输入变化时该阶段及后序阶段过期；不把旧确认删掉。改变文风不会使无关的来源身份、要求或大纲自动失效。阶段必须按当前前序确认顺序推进，不能跳过要求／大纲来声明交付。证据不足需明确说明，仍不能绕过写作证据门禁。七阶段全部为当前版本后才能结束；有不足或问题的决定使任务为 completed-with-issues。

引导记录位于 `.scholarflow/runs/workflow_<id>/`，保存 input.json、plan.json、run.json、checkpoint.json 和 decisions/。独立 `.scholarflow/workflows/current.json` 只指向当前引导任务。等待输入不占用模型／检索阶段的 ACTIVE_RUN，阶段执行继续使用已有项目互斥锁；引导确认、暂停、取消及结束在活动阶段或待恢复事务存在时拒绝，不冒称已中止网络调用。后续调度器需要关联子阶段并统一预算与控制。

所有预览均只读，操作者 RPC 以原项目／工作区／会话／peer 限定十分钟预览，至多八项。确认复验完整阶段摘要、当前配置、检查点与指针，事务提交决定与 run/checkpoint；进程损失采用既有原前像／后像事务恢复，不重建目标或重放已确认阶段。暂停后保持原输入；配置改变阻止恢复，需明确取消并创建新目标；历史任务保持只读，产物与问题保留。
