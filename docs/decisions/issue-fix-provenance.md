# 问题修复候选与同版本复查

日期：2026-10-05。依据 PRD SF-024、SPEC 18 的 Proposal 接受协议与 19.4 的问题关闭规则。

问题位置必须匹配当前主稿摘要、AST 段落身份、段落摘要与引文；旧稿或无位置的问题拒绝猜测定位。界面可跳转并聚焦保存稿的实际段落，保持未提交编辑缓冲。生成修复明确预览完整普通段落范围及模型发送内容；复杂公式、代码、图片或表格段落返回能力限制。

修复复用现有有限写作执行器、固定修订阶段资源、预算、暂停、取消和不可变 Proposal。建议以可选 reviewIssue 字段保存原问题身份和摘要，另存不可变依据记录；旧建议格式可继续读取。生成后问题为 proposed-fix，正文未改变。接受仍校验正文版本、范围、原文、引用、问题依据和建议摘要，保留原稿与版本历史。拒绝最后一个有效候选恢复原未解决状态，候选档案保留。

接受后针对新稿自动执行确定性复查，旧模型问题保持待复查，不把模型推荐或用户接受当作语义正确证明。明确同版本模型复查通过后才关闭相应问题，历史报告保持原状态。规则复查若因并发或其他原因失败，返回已保存修订身份和 needs-attention；不把已成功的接受冒充失败，也不重放正文修改。

接受事务同时保存待复查标记；规则报告与完成标记在同一事务中发布，完成标记引用不可变报告和摘要。接受后、复查前中断时，再次确认接受会幂等保留正文并补做当前对应版本的待复查，不重复写稿。已有之后的人工编辑时停止旧版本补查，不将旧报告投射到新稿；完成标记缺少匹配报告时显示需要处理。

领域验证：`pnpm typecheck` 与全分层测试 196/196。TEST_ONLY 测试覆盖第二重复段范围、冻结问题依据、生成不改稿、多个候选全部拒绝后保留原风险决定、接受后规则复查与明确语义闭环、旧问题或伪造范围拒绝、复查失败后的已保存修订、接受后复查间隙恢复及重复接受幂等。

真实 DSH 0.2.0-rc.2 独立 DSH_HOME 的 `--live-model` 验证通过：实际模型审查问题可跳转保存正文并聚焦准确段落；修复预览取消不改变 ledger 或创建运行；使用宿主当前模型生成后问题为 proposed-fix，正文尚未改变；拒绝候选后问题回到 open，正文、原资料与引用保持原字节。确定性复查接受路径和明确语义关闭由独立领域测试覆盖，未将真实拒绝测试冒称为真实接受。证据 `.dsh-tmp/model-smoke.json` 忽略，不修改 desktop profile 或凭据存储。完整 V1 验收仍未完成。
