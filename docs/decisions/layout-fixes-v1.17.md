# v1.17 导航与要求页布局修复

日期：2026-10-11。合同：文档工作区 `../docs/ScholarFlow_PRD_v1.17.md` 与配套 SPEC。用户已确认实施；使用 drive-to-completion 和 frontend-design 的克制布局方向，沿用现有暖纸主题、CSS tokens 和 React。

## 改动

- SF-172：移除更多菜单的第二处自动左边距，资料／检查／更多连续靠右。
- SF-173：来源与文风的折叠标题具有完整 40px 点击行，主表单到附加区间距 24px，标题到展开内容 16px，操作行与下一分区分离。要求文件、参考资料、联网分别成组；封面复用主表单字段网格。
- SF-174：明确 checkbox 行方向及文字换行，清除要求页中向导标签的竖排／大外边距。模板列表伸展到同一左边线，字段标签顶部对齐。四个内置模板显示中文名，原 qualifiedId、digest、scope 和资源字节保持。
- 响应式以要求页内容宽度为准，小于 560px 时字段叠放，勾选框和文字继续同行。没有增加运行时、通用防御框架或业务存储协议。
