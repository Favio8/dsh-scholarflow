# 项目记忆条目来源与更正历史

日期：2026-10-05。依据 PRD 13.2／SF-018／SF-028／SF-034 和 SPEC 15.2–15.3。

三份记忆 Markdown 保持唯一可编辑内容真值。ledger 的可选 memoryFiles 只保存当前文件摘要与条目投影：类型、原文／标题上下文摘要、UTF-16 范围、确认状态、来源用户操作、会话和时间。段落通过源位置 AST 读取；表格、代码、HTML 等保持普通文本，不从中推断术语关系、事实或可执行命令。旧项目没有条目来源时显示原文和未知来源，不猜测旧作者、时间或补写元数据。

保存／明确纳入记忆仍需已认证操作者的当前项目、会话、ledger 版本和文件 SHA。文字是否进入阶段上下文继续由 approvals.json 的明确整文件确认与实际 SHA 决定，外部修改不自动注入。确认操作同时以事务提交 Markdown、ledger 投影、整文件审批与不可变 context/history/memory_change_<id>.json；没有第二份可以自由修改的记忆正文。

更正记录保存完整前后原文、摘要、原条目元数据、被替代条目 ID、操作者会话、时间及用户说明。只有旧投影与旧原文完全对应、来源操作快照可校验、同标题上下文中的文字在前后都唯一时，才保留未修改条目的原始来源；重复文字、外部编辑、上下文变化或来源缺失不猜测身份。更正／删除的旧来源仍在历史记录中，不覆盖原文档案。

来源展示逐项校验不可变操作的项目、路径、身份、原文 SHA、原始条目和原确认时间／会话，不能仅凭 ledger 里的来源 ID 声称它已验证。缺失、改变或超出单次 64 个来源操作校验限额时保留原文与历史，显示来源未知；用户重新明确确认会记录本次操作，不能伪造已丢失的原作者。该来源状态不会代替现有的整文件授权判断。

每文件最多 2000 个条目、更正记录最多 4 MiB、项目最多 1000 个记忆操作；超限不丢弃内容后继续保存。历史读取仅展示所选文件最近 100 次操作，其余记录保留。类型由实际的 decisions／terminology／writing-memory 文件确定，不把模型推测自动升级为已确认记忆。Agent 工具没有保存或确认记忆权限。

研究决定改变仍要求重新确认大纲；文风与记忆变更使相关审查失效，并通过实际 Profile／记忆／审批 SHA 使旧阶段输入停止。正文、原始材料、其他项目、全局模板与 Skill 目录不随记忆编辑改变。更细的术语影响章节提示和未提交 Profile／记忆缓冲仍需后续验证。

验证：七项 TEST_ONLY 集成覆盖精确 CRLF／Unicode 原文与来源、唯一不变条目来源保留、重复条目删除不猜测、外部编辑拒绝自动注入、表格／代码静态保存、冷读取与损坏历史拒绝、丢失来源后明确重确认、保存事务中断恢复且不重复历史。完整 pnpm test 259/259、typecheck 通过。真实 DSH 操作者 UI 已验证记忆条目来源、确认历史、实际会话和跨会话冷恢复，原材料与正文保留。
