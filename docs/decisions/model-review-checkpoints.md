# 有限模型审查与持久恢复

日期：2026-10-05。依据 PRD SF-023／024／027，SPEC 的同版本审查、运行快照、短期写锁与有限重试约束。

模型审查只读取已保存主稿、明确项目要求、相关论点、当前有效的定位证据、已确认记忆、项目文风、Review Profile 与本审查阶段固定 Skill。完整审查范围在预览中说明；超过上下文预算时拒绝，不隐式丢弃关键证据。宿主模型与凭据服务保持唯一接入点，没有另建 Agent Loop。

冻结计划、input.json、run.json、checkpoint.json 与实际 Skill 说明在第一次调用之前持久化。模型调用不持有项目写锁，每次请求前重验项目输入，调用次数先登记再发送。输出只允许论证／文风检查、问题与明确旧问题复查；真实源码块、唯一连续原样引文及关联身份都由领域层验证。模型不能提交正文、升级来源身份、覆盖确定性阻塞或自报流程完成。

本阶段最多一次格式修复、两次已知临时错误重试，遵守提供方等待窗口；认证和配置错误不重试。暂停保留输出、计费次数、修复次数和等待窗口，恢复原预算。确认操作绑定当前用户、项目、会话和输入摘要。原进程存活时不接管；失去响应的调用仍计入预算。取消的迟到响应不能发布报告。

报告与模型记录不可变，链接父报告及运行。遗漏旧问题不等于通过；只有明确针对当前正文复查通过，才关闭其问题记录。报告已持久化而运行未保存终态时，通过固定报告身份和完整内容复核后只补终态，不再调用、不重发报告、不改动之后的人工正文。检查点或权威状态被外部修改时拒绝覆盖。

验证：`pnpm typecheck` 与全分层测试 190/190。新增领域测试包括重复段落位置、伪造位置与范围身份、有限格式修复、实验 B0 不可绕过、暂停与跨会话恢复、失联调用计费、产物保存间隙恢复、输入改变停止、关联重试、取消、并发启动、429 等待窗口、检查点篡改与单次输出预算。模型回调固定数据均标注 TEST_ONLY。真实宿主 G0 已通过；真实提供方审查验证结果单独记录，不以领域测试替代。

首次实际审查暴露了 4096 token 输出预算在当前宿主推理模型上耗尽后没有 JSON 的情况。宿主会话记录结束原因 `max-tokens` 和实际用量，未发布报告。审查现在冻结并预览单次输出预算 16384 tokens；适配器验证最多 32768，达到预算单独返回失败，不自行续写或重试。上下文规划预留完整输出预算及封装开销，旧检查点保持原输出预算。该改动不会把推理预算耗尽冒充格式错误。

另一次实际输出将 checks 写成对象，经过一次修复仍不符合数组合同，因此运行失败且原报告保留。系统说明及唯一修复请求现在包含精确 JSON 数组形状示例，不将无效对象隐式转换为可发布报告。端到端测试遇到真实失败会立即报告，减少等待并保留原运行的两次计费记录。

真实 DSH 0.2.0-rc.2 独立 DSH_HOME 的 `--live-model` 重跑通过：使用宿主当前 deepseek-official / deepseek-flash，预览取消不创建运行／改变 ledger；固定 research-results-integrity 审查阶段说明，发送确切保存正文与有效证据；当前调用结束后暂停，恢复复用已验证输出，无追加计费请求；两个模型检查真实执行，问题引文对应实际 UTF-16 源码位置。正文、原资料和部分支持论点状态保持不变，同版工作草稿导出、冷恢复与普通会话边界继续通过。凭据文件只做前后摘要比较。证据 `.dsh-tmp/model-smoke.json` 忽略，不将 fixture 当作真实学术资料。完整 V1 验收仍未完成。
