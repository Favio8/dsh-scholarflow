# 用户编辑候选与重新校验

日期：2026-10-05。依据 PRD SF-016 与 SPEC 18.3 的候选编辑、确认和版本协议。

用户可以在正文建议或问题修复差异中编辑单条候选。章节编辑只编辑本节正文，标题、相邻章节和子章节仍由 AST 范围合同保护；实际段落数量变化时须提供完整论点映射，不能自动猜测关联。编辑不调用模型，不更改原候选和主稿。

预览重新构造 Proposal，校验当前稿件版本、原文范围、选区、引用、证据原文件摘要和章节映射，并重新报告数字与限定条件变化。选区必须保留本选区的引用 token，即使同键在别处出现也不能丢失。章节与全文候选不能加入原候选、目标原文及已声明依赖证据之外的来源；有依赖证据的候选不能删掉全部依赖来源引用。这些规则不能证明语义正确或学术真实性。

明确确认后以新身份保存候选，derivedFrom 固定原建议身份与摘要，独立确认记录保存编辑理由、用户会话和计划摘要。原建议字节和状态保留。保存前重新计算配置、ledger、完整审查依赖和原建议摘要，短写锁内再次核对；期间外部稿件、文风、资料或原建议改变时停止发布。建议、出处记录与 ledger 在同一事务中发布，不用模型运行重放用户编辑。

Host 预览只属于当前操作用户、工作区、项目、会话和 ledger 版本，十分钟过期，最多八份；取消只清除该预览。新候选仍需要独立接受。问题修复编辑保留问题来源，全部有效候选拒绝后恢复此前明确的风险决定；接受不直接关闭语义问题。

验证：分层测试 202/202，类型检查通过。领域测试覆盖预览零写入、原候选不可变、新候选出处、数字复查、第二重复段落范围、旧建议接受拒绝、伪造确认、原建议/文风/正文/原材料变更、不同会话、重复引用防丢失、来源范围、依赖引用保留、章节映射和多个问题修复拒绝后恢复原风险决定。

真实 DSH 0.2.0-rc.2 独立 DSH_HOME 的 `--live-model` 验证通过：实际模型修复候选可手工编辑，校验预览取消不变更 ledger；确认保存后显示新候选，正文与原建议字节不变；拒绝新候选保留原候选待审阅，最后拒绝原候选恢复 open。宿主凭据文件摘要不变。证据 `.dsh-tmp/model-smoke.json` 忽略，不声称完整 V1 验收完成。
