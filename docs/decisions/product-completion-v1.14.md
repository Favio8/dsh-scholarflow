# v1.14 产品链路修复与验证

日期：2026-10-11。对应上一级 `docs/ScholarFlow_PRD_v1.14.md` 与 `docs/ScholarFlow_Design_SPEC_v1.14.md`，继承此前完整版本链。用户明确授权完成 PA-01–17 的修复与新增能力。代码在 `style/paper-composition`；本轮没有发布或推送。

## 实现

- 写作与快捷改写共用已确认政策、固定阶段 Skill、文风和已批准记忆。快捷调用保存实际输入、规则摘要与使用记录；未知提供方输出上限不会被插件替换为固定配额。
- 恢复大纲、审查、修改、项目设置、版本、运行历史以及项目 Skill / 文风记忆 / 高级要求 / 引导流程入口。
- 要求表单只更新其负责的字段。资料选择、来源句柄和联网独立保存；资料变更不再导致假要求冲突，也不会丢掉独立追加的材料。旧单文件要求来源可显式移除。
- Skill 可新建、预览、保存不可变版本、编辑与复制。安装后另行确认项目版本与阶段；历史改写引用也阻止误卸载。
- 资料可直接解析、重读、查看、排除与重新选用。要求文件、工作区文件夹、外部文件夹与图片转写均有创建后的管理入口。
- 改写决定失败保留待同步状态，重试不重复合并；已接受位置可明确记录经过编辑追踪的位置。版本比较显示实际差异，恢复创建新修订。
- APA 7 使用 Citation.js 的 CSL 数据与样式；BibTeX/RIS 先预览候选与重复项再登记。导入不会创建定位证据或核验出版身份。
- 本地 PNG/JPEG 按真实字节与摘要打包，Word 嵌图、LaTeX 引用包内资源；远程图不自动下载。预检后资源变更拒绝旧交付计划。
- 质量报告统计本次实际导出稿，过期审查标为历史结果。工作草稿提示、完整 ZIP 和质量报告入口可见。
- 纸面/版心、首行缩进、空页码位与真实 AI 修改标记已接到组件。窄窗分屏上下排列，资料为紧凑文件行。无真实分页数据不显示伪页码。
