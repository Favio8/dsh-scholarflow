# 要求来源草稿校验与向导控件修复

日期：2026-10-10。用户报告：仅选择作业要求图片文件夹时出现 `requirements` 的 `too_small` 原始异常；读取停留在“准备中”；来源列表与前后翻页按钮样式不协调。

本次修复既有合同，不新增产品范围：PRD v1.2 SF-048／049／051／066、AT-45／46／49／66，以及 v1.6 SF-091／AT-91。题目填写时可暂空、正式创建前必填；要求候选在采用前不写入输入，下一步需要已确认要求（父目录 `docs/entry-wizard-presets/02-wizard-design.md` §4、§4.2）。基线文档保持冻结。

## 根因与决定

1. `creationSpec` 是正式提交合同，题目与要求均不可空。读取、结构化、重试、候选采用却也用它校验尚未填完的草稿，客户端与宿主两侧都会提前拒绝。新增从同一对象派生的 `requirementDraftSpec`，仅允许这两个文本在准备阶段暂空，仍要求存在手填文字或已选来源，保留长度、路径、外部句柄和其他字段校验。正式创建与持久化继续使用原来的严格合同。
2. 整理开始前先校验，整个异步流程在 `finally` 清理进度计时器并设置终态；读取启动失败、结构化失败与停止均不再残留“读取中”。新操作清除旧的读取展示；迟到结果仍按操作编号拒绝。
3. 手填文字独立于文件来源，允许零文件读取；零文件不虚构成员计数。全部文件失败且没有手填文字时，宿主在调用模型前拒绝结构化，不能把任务的 `ready` 状态误当成有可用文字。
4. 候选快照与采用请求使用相同的草稿规范化，避免默认字段导致假过期。采用可以补充要求文字，但不替用户编造论文题目。来源未确认时在第一步给出整理／手填提示；从旧的第三步草稿创建时也检查要求，避免再暴露 schema 错误。
5. 原始 Zod 异常（含桥接后的 JSON 字符串）转换成中文字段提示，保留已填写内容。
6. 文件夹使用紧凑的标题、文件数、文件图标和对齐移除按钮；成员名称与读取状态共用一行，避免读取后再堆一份重复列表。来源操作与导航使用同一主题令牌；前后翻页同高同字号，后退为弱按钮、前进为主按钮，方向使用 SVG。窄栏下来源按钮文字允许换行，键盘焦点与 44px 移动命中框保留。
7. 真机截图发现 `.sf-body button:not(.sf-native-tools *)` 与 `.sf-paper-project button:not(.sf-native-tools *)` 的父级规则覆盖了向导样式：字号回到 15px，弱按钮重新出现边框。通用按钮／选择器的 fallback 现显式避开 `.sf-wizard` 后代；组件测试同时加载真实父级 CSS，防止独立页面好看、宿主里仍旧被覆盖。移动最小高度由向导的响应式变量统一控制，避免 `min-height` 被高优先级组件规则覆盖。

## 验证边界

- `tests/contracts/creation-spec.test.ts`：来源独立输入、题目暂空、外部来源／路径边界、候选采用与正式提交校验、原始错误转译。
- `tests/e2e/requirements-intake.mjs`：真实 React 组件＋明确的受控服务响应；8 项浏览器场景覆盖截图的三图片文件夹、启动失败、结构化失败、停止迟到响应、候选采用、手填要求、错误文案和深浅主题宽窄布局。图片识别／模型输出是测试替身，不冒充真实模型验证。
- `tests/e2e/requirements-intake-host.mjs`：安装版宿主＋隔离 profile 的真实 RPC、文件读取与解析；5 项检查覆盖空题目／空要求下读取三个文本文件、单成员重试、手填文字零文件路径、不可读文件拒绝结构化、正式提交拒绝及原文件保持不变。无模型调用。
- 四层回归 551/551、类型检查与构建通过；17 个渲染检查通过。
- 外观审计首轮发现 320px 来源按钮截断，第二轮截断归零、暴露 720px 命中高度 42px。停止重复同一审计，改用真实宿主 computed-style 专项定位 CSS 层叠并验证修复：深／浅两主题 × 1440／720／320px 共 **6/6** 通过，来源无文字截断或水平溢出，窄屏来源及导航命中高度均 ≥44px；前后按钮均为 13px 字号，后退边框透明。对比度检查通过。最终证据 `.dsh-tmp/intake-controls-report.json`、`.dsh-tmp/intake-controls-probe-final.log`；先前两次审计的失败日志保留，不改写为通过。
- 安装版宿主截图：`.dsh-tmp/intake-host-sources.png`、`.dsh-tmp/intake-host-navigation.png`。受控 UI 测试最终证据 `.dsh-tmp/intake-ui-with-parent-styles.log`；分层回归 `.dsh-tmp/intake-regression-final.log`。

本轮没有使用用户实际作业图片、未执行付费模型识别、未自动重启正在使用的桌面宿主。桌面链接此工作副本，构建后需保存当前编辑并完全退出重开，才能清除旧模块缓存。
