# 按节初稿顺序与真实接受检查点

日期：2026-10-05。依据 PRD 7.1、9.4、SF-013／SF-026／SF-027／SF-028 和 SPEC 19.2。

按节初稿须先绑定已确认引导目标的原累计预算。用户预览完整大纲的执行顺序，明确选择在正文之后生成的摘要／结论；不按标题相似度猜测角色。已有非空章节正文原样保留，仅为缺失或空白章节逐节创建候选。父章节须先于子章节，推迟摘要父章节时必须同时推迟其整个子树。章节插入位置仍使用已验证的源位置 AST，不重排或删除人工正文。

每节在真实当前正文上另行预览模型、输入范围、固定 Skill、证据及费用边界，确认后先以事务登记其唯一 childRunId／childPlanHash，再复用已有有限写作执行器。摘要与结论的子计划实际输入已保存主稿，不能使用尚未接受的其他候选或计划结果。等待接受不占用 ACTIVE_RUN；生成中的单节继续使用项目互斥锁和原累计调用／时间额度。不存在模型自己调度下一节或自动接受正文的代理循环。

父输入保存原配置、材料摘要、证据、要求、论点、大纲、文风、记忆与实际 Skill 资源作用域摘要，冻结模型及原 workflowId。已由本顺序接受的正文／锚点／建议状态变化不使无关作用域过期；其他人工稿、原始材料、文风、记忆、Skill、大纲、要求、模型或总目标改变时停止旧顺序，要求明确重新规划剩余章节。拒绝候选不算进度，也不自动付费重试。

接受进度须核对原运行与冻结计划、执行检查点中的原建议、操作员编辑候选的完整不可变来源链、ledger 接受状态，以及修订清单的 origin／parentRevisionId／baseDocumentHash。原稿快照应用已接受差异后的字节必须与修订快照、当前主稿和引用清单一致；有复数接受、断链、缺失前像或接受后人工改稿时不能猜测继续。只读进度读取不写入父检查点；下一次明确确认原子采用这份接受事实。

没有定位证据的单节只产生固定 `[待补：…当前尚未完成…]` 结构候选，段落论点映射为空，零模型调用。它同样必须经过差异审阅才能写入主稿，不增加事实、来源、结果或支持状态。已有证据但已过期／不可用时停止，不降级成似乎成功的生成。操作员可明确编辑待补候选，但仍需重新校验并另行接受。

父记录位于 `.scholarflow/runs/draft_<id>/`，有 input.json、plan.json、run.json、checkpoint.json 和不可变 decisions/；`.scholarflow/drafting/current.json` 指向当前顺序。父记录使用明确的 draft 身份，单节子运行继续进入原写作历史，避免将等待用户接受的顺序误交给单节恢复器。登记后执行前的暂停／取消或总目标改变禁止旧子计划重放。事务中断只恢复原登记身份；没有执行记录时不猜测调用是否需要重放，可明确取消旧顺序再重新预览。冷启动和另一会话可读取原记录，恢复需新操作者预览。

父输入另存初始写作阶段的固定 Skill 版本清单。资源卸载扫描核对父流程 input／plan／run／checkpoint 的身份与摘要，保留初稿历史引用；当前项目解除绑定不删除这份历史引用。引导目标自身不声明固定 Skill，它的实际阶段运行分别保留引用。未知目录、不完整／损坏记录，以及缺少固定资源清单的早期初稿记录仍按引用未知阻止卸载；不把“扫描不到”当成可删除。

全部章节接受／保留后仅结束为 completed-with-issues，保留缺口与未关闭问题；继续通过原完整审查与同版交付门禁。不将“有正文”提升为跨节语义一致、真实研究完成或正式 V1 验收。完整阶段自动调度和跨节语义一致性最终签收仍待完成。

领域验证：11 项 TEST_ONLY 集成覆盖无写入预览、明确排序、人工章节保留、零调用待补、两节实际接受后文输入、累计额度耗尽停止、拒绝、操作员编辑链、冷恢复、并发确认、原材料／文风／人工稿变化、登记与执行之间暂停、修订前像损坏及事务登记中断。真实 DSH 模型测试已验证顺序预览取消／确认、单节预览取消无登记、暂停与冷跨会话读取；此真实 UI 验证没有执行完整多节付费初稿，不能替代三类样例最终签收。

真实测试还发现 Skill 调用阶段的延迟读取可能覆盖刚选择的阶段，使确认按钮变灰。项目 Skill 页面现在保留未提交阶段选择；成功确认后才重新采用保存阶段。
