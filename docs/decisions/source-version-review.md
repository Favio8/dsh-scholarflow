# 非 DOI 来源疑似重复与具体版本

日期：2026-10-05。依据 PRD SF-010、SPEC 13.4。arXiv 格式与版本语义核对 [官方标识说明](https://info.arxiv.org/help/arxiv_identifier.html)：明确的版本后缀保留，无后缀不推定为首版。编号解析只检查已支持语法，不证明作品存在、出版身份或内容支持。

来源登记先预览标题、类型、年份、本地资料和规范化标识；同一 arXiv 作品的版本关联及相似标题显示疑似重复。标题比较采用 Unicode 规范化后的保守规则，只有提示权，不能升级身份或自动合并。精确规范化 arXiv 元数据重复沿用既有记录；不同具体版本或不同本地文本需用户说明为什么保留独立来源。未提供版本的标识与 v1 不相等。DOI 与同一本地资料的既有登记保护继续生效。

用户可以取消或沿用已有来源；这不把新资料自动附到旧来源、不迁移任何证据。确认独立来源需要列出的全部既有来源身份和摘要一致，记录用户会话、理由、观察到的关联与时间。Source、新决定档案与 ledger 一起事务提交。候选预览只属于当前操作用户、项目和会话，十分钟过期，最多八份。项目配置或来源观察改变后停止，短写锁内再次检查输入，不能借旧预览覆盖更正记录。

来源类型与未知年份可由用户明确输入。实际结果类型的登记仍不代表存在可定位测量；出版身份、全文范围与证据支持保持独立。不同文本保留各自 materialId、内容摘要、来源 ID、引用键和证据，不因相似标题或同作品关系进行合并。

领域测试覆盖现代/旧式 arXiv 编号、明确/未指定版本、格式拒绝、预览零写入、理由门禁、规范化精确元数据去重、不同文本版本、原证据/引用/主稿/原资料保留、来源观察变更、伪造计划与不同会话。真实 DSH 0.2.0-rc.2 新独立 DSH_HOME 的 g0 测试通过来源登记预览、取消和确认并完成其余纵向链路。arXiv 文本版本分支由明确 TEST_ONLY 的领域数据测试，未冒称为外部身份核验。完整 V1 验收仍未完成。
