# v1.16 写作简化与格式修复

日期：2026-10-11。合同：文档工作区 `../docs/ScholarFlow_PRD_v1.16.md` 与配套 SPEC。用户已确认实施；包版本仍为 1.0.0，未发布 npm 包。

## 实施

- SF-167：一个按钮串联规则与当前会话模型检查，可先保存未提交正文。检查页与正文核对共用当前问题投影，文献用标题显示；同书目身份／缺少原文只提示一次，五项尚未执行的语义检查合成一个明确的未完成项。原问题与检查方式保留，未知不改为通过。人工复核表单退出界面。
- SF-168：基于带源位置的 AST 逐段切换加粗／斜体，空白在标记外，已有强调按选区拆分；链接内部格式保留在链接文字内。格式操作恢复真实选区，精确的插入／删除调整局部字体范围，预览与 Word 同源。
- SF-169：来源集合与实际引用使用相同 DOI／书目身份分组；主来源晚于别名遍历时也只算一次。相同 DOI 的不同本地文本自动关联书目；题名相同的疑似记录一次明确确认。原始来源、引用键、证据和材料保留。
- SF-170：资料／检查直达，更多仅写作要求、项目设置、版本历史；历史包含稿件、运行恢复和导出记录。章节结构由正文目录打开并可真实保存；修改建议与正文恢复留在检查区。独立引导、Skill、记忆、高级要求、导出与分屏入口取消。
- SF-171：主格式条只留常用操作，局部字体／段落与全文排版按需展开；要求字段对齐，文风和写作模板在要求页应用；子页不重复展示成稿进度。删除旧审查子区块自动加边框的规则。
