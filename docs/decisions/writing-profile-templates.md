# 文风模板与项目副本

日期：2026-10-05。依据 PRD SF-017、SF-034、设置中的 Writing Profiles，及 SPEC 15.1、23.5。

六份内置模板覆盖课程论文、文献综述、研究论文的中英文表达规范。
新项目复制对应文本并记录来源，已有项目不会随插件或库变化自动替换。
设置页可导入 UTF-8 Markdown／TXT、预览取消、保存私有版本、复制、编辑为新版本和导出说明。
私有模板存于 `<DSH_HOME>/scholarflow/profiles/`，与全局 Skill 和 Academic Skill 库分别管理。
每个固定版本验证身份和完整模板摘要；读取限额、普通目录、硬链接／目录链接拒绝与不可变保存均有测试。

概览中的复制操作冻结项目、配置、ledger、当前文风和来源摘要，确认时全部重验。
确认复制归档原文本、来源与 preset，写入本项目独立文本及复制来源；手工编辑也保留原文历史。
结构化表达偏好进入项目实际说明文本，后续模型阶段冻结这份实际文本。
模板复制与项目定制均不授予工具／脚本权限、不改正文，也不提升来源身份或证据核验状态。
来源记录损坏时保留文件并显示自定义文本，不把未经校验的记录作为已确认来源。

验证：`pnpm typecheck`、`pnpm test` 173/173；真实 DSH 0.2.0-rc.2 独立 DSH_HOME
验证导入／复制预览取消、原 BOM／CRLF 字节、导出、新版本保留旧版本、项目副本历史与冷重启。
随后真实 DeepSeek 文本阶段完成章节与选区候选、接受及跨会话暂停恢复；凭据通过 Host 服务，未复制或打印。
