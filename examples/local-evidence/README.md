# 三类本地证据练习

这些是教学示例，均标记为 `TEST_ONLY`。材料是随插件编写的练习说明，不是出版论文、实验记录或在线检索结果；没有虚构 DOI、作者或实测数据。

在新的 DSH 工作区复制 `requirements.md` 和 `source-notes.md`，选择 `tasks.json` 中一种任务类型。初始化需自行预览确认，不提供带固定项目 ID 的已初始化目录。

1. 登记、解析要求文件，确认字数统计口径与参考文献数量。
2. 登记说明文件为笔记，建立一个本地来源；出版身份保持未核验。
3. 在原文中定位关于证据层次的段落，明确论点仅适用于这份练习说明。
4. 确认“摘要／证据讨论／人工备注”大纲。人工备注先手工保存；起草讨论，再根据已接受正文生成摘要。
5. 每节候选先审阅差异再接受。运行规则审查，保留未知项，导出工作草稿。

课程分支练习要求确认与引用；综述分支明确只有一份教学资料，不能声称系统检索或完整综述；研究分支没有实验与结果，必须保留待补和 B0。三者均不应导出为“已审查草稿”。

`tests/integration/paper-type-examples.test.ts` 从这些实际文件读取和解析材料，贯穿初始化、要求、来源、定位证据、论点、大纲、按节候选、人工接受、冷恢复、规则审查和同版三文件导出。它使用明确标记的固定模型适配器与测试存储，不会付费，不代表真实模型或 Host 验收；真实 DSH／模型回归另行运行。
